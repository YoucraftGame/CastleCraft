# 检测小程序源码

Windows .NET Framework 4.8，C# 编译器 csc.exe。引用 System.Windows.Forms、System.Drawing、System.Web.Extensions、System.Core、System.IO.Compression、System.IO.Compression.FileSystem。目标 winexe/x64。

只读 CLI：--discover 或 --check --castle <目录> --minecraft <版本目录> --game-dir <实际游戏目录> --java <javaw.exe>。仅“打开完整教程”按钮调用系统文档关联，不会运行游戏。package-manifest.json 必须与 EXE 同目录。

build_package.py 是维护者打包脚本，本机路径只用于读取已安装的模组，不是用户安装步骤。重打包应同步更新本包清单，不把未部署开发源码当作已验收成品。

新增 VulkanDoctor.cs 必须与 CastleCraftDoctor.cs 一起编译，额外引用 System.Management.dll。Vulkan 检测调用系统 Loader；安装按钮只在用户点击并选择安装器后校验签名并请求 UAC。官方安装向导自行下载及选择驱动。本程序没有静默安装接口。
